# 快速启动指南

## 环境准备

### 系统要求

- **Node.js** >= 18
- **MySQL** >= 5.7
- **npm** 或 **yarn**

### 检查环境

```bash
# 检查 Node.js 版本
node --version

# 检查 npm 版本
npm --version

# 检查 MySQL 是否运行
mysql --version
```

---

## 第一步：安装依赖

```bash
cd server
npm install
```

如果遇到依赖安装问题，可以尝试：

```bash
# 清除缓存
npm cache clean --force

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

---

## 第二步：配置环境变量

在 `server` 目录下创建 `.env` 文件：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_DATABASE=charging_station

# JWT配置
JWT_SECRET=super_secret_jwt_key_change_in_production

# 服务端口
PORT=3001
```

**⚠️ 重要提醒：**
- 将 `DB_PASSWORD` 改为你的实际 MySQL 密码
- 生产环境请修改 `JWT_SECRET` 为更安全的密钥

---

## 第三步：数据库初始化

### 3.1 启动 MySQL 服务

确保 MySQL 服务已启动：

```bash
# Windows
net start mysql

# macOS (使用 Homebrew)
brew services start mysql

# Linux (使用 systemctl)
sudo systemctl start mysql
```

### 3.2 创建数据库

打开 MySQL 命令行或 MySQL Workbench，执行：

```sql
CREATE DATABASE charging_station CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

或者使用命令行：

```bash
mysql -u root -p -e "CREATE DATABASE charging_station CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

---

## 第四步：启动项目

### 开发模式（推荐）

```bash
npm run dev
```

### 生产模式

```bash
# 构建项目
npm run build

# 启动服务
npm start
```

## 常见问题排查

### 1. 数据库连接问题

#### 错误：`ECONNREFUSED` - 连接被拒绝
- **原因：** MySQL 服务未启动
- **解决：** 启动 MySQL 服务

#### 错误：`Access denied` - 访问被拒绝
- **原因：** 数据库用户名或密码错误
- **解决：** 检查 `.env` 文件中的 `DB_USER` 和 `DB_PASSWORD`

#### 错误：`Unknown database` - 数据库不存在
- **原因：** 数据库 `charging_station` 未创建
- **解决：** 执行创建数据库的 SQL 语句

### 2. 模块加载问题

#### 错误：`Cannot find module` - 找不到模块
- **原因：** 依赖未安装或安装不完整
- **解决：** 
  ```bash
  rm -rf node_modules package-lock.json
  npm install
  ```

#### 错误：`ECMAScript imports and exports cannot be written in a CommonJS file`
- **原因：** TypeScript 配置问题
- **解决：** 确保 `package.json` 中有 `"type": "module"`

### 3. 端口占用问题

#### 错误：`EADDRINUSE` - 端口已被占用
- **原因：** 3001 端口被其他程序占用
- **解决：** 
  ```bash
  # 查找占用端口的进程
  lsof -i :3001  # macOS/Linux
  netstat -ano | findstr :3001  # Windows
  
  # 或者修改 .env 文件中的 PORT
  PORT=3002
  ```

### 4. TypeScript 编译问题

#### 错误：TypeScript 编译错误
- **原因：** TypeScript 配置或代码语法问题
- **解决：** 检查 `tsconfig.json` 配置，确保使用正确的模块解析方式
