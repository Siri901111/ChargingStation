## 问题修复

已修复删除和更新接口的路由问题，现在所有接口都可以正常使用。

## 正确的请求方式

### ⚠️ 重要：URL格式

**正确格式**（推荐）：
```
DELETE /api/stations/1
PUT /api/stations/1
```

**错误格式**（会导致404）：
```
DELETE /api/stations/    ❌ 末尾有斜杠但没有ID
PUT /api/stations/       ❌ 末尾有斜杠但没有ID
```

## 接口测试示例

### 1. 获取充电站列表

```bash
GET http://localhost:3001/api/stations?page=1&pageSize=10&status=2
Authorization: Bearer <token>
```

### 2. 获取单个充电站

```bash
GET http://localhost:3001/api/stations/1
Authorization: Bearer <token>
```

### 3. 创建充电站

```bash
POST http://localhost:3001/api/stations
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "新充电站",
  "city": "北京市",
  "fast": 10,
  "slow": 5,
  "status": 2,
  "person": "王站长",
  "tel": "13800138000"
}
```

### 4. 更新充电站 ✅

```bash
PUT http://localhost:3001/api/stations/1
Authorization: Bearer <token>
Content-Type: application/json

{
  "status": 3,
  "person": "李站长"
}
```

**注意**：URL 中必须包含站点ID，例如 `/api/stations/1`，不能是 `/api/stations/`

### 5. 删除充电站 ✅

```bash
DELETE http://localhost:3001/api/stations/1
Authorization: Bearer <token>
```

**注意**：URL 中必须包含站点ID，例如 `/api/stations/1`，不能是 `/api/stations/`

## 常见错误及解决方案

### 错误1: `Cannot DELETE /api/stations/`

**原因**：URL 末尾有斜杠但没有ID

**解决**：
- ✅ 使用：`DELETE /api/stations/1`
- ❌ 不要使用：`DELETE /api/stations/`

### 错误2: `无效的站点ID`

**原因**：ID 参数为空或不是数字

**解决**：
- 确保 URL 中包含有效的数字ID
- 例如：`/api/stations/1` 而不是 `/api/stations/abc`

### 错误3: `404 Not Found`

**原因**：路由未匹配

**解决**：
- 检查 HTTP 方法是否正确（GET/POST/PUT/DELETE）
- 检查 URL 路径是否正确
- 确保路径参数格式正确
