# 充电站管理平台 - 项目文档总览

## 项目简介

这是一个**新能源汽车充电站管理平台**的后端系统，采用 Node.js + Express + TypeScript + MySQL 技术栈开发。系统提供充电站管理、用户权限管理、营收统计、设备监控等功能的完整 API 服务。

## 技术架构

### 后端技术栈

- **运行环境**: Node.js >= 18
- **Web框架**: Express.js
- **编程语言**: TypeScript
- **数据库**: MySQL >= 5.7
- **ORM框架**: Sequelize
- **身份认证**: JWT (JSON Web Tokens)
- **密码加密**: bcryptjs
- **开发工具**: nodemon + tsx
- **模块系统**: ESM (ES Modules)

### 前端技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **HTTP客户端**: Axios

## 功能模块

### 1. 用户管理模块

- **用户登录**: JWT身份认证
- **用户注册**: 新用户注册功能
- **用户列表**: 分页查询、搜索筛选
- **权限管理**: 基于角色的权限控制（admin/manager/user）
- **用户操作**: 设置权限、禁用/启用、删除用户

### 2. 充电站管理模块

- **充电站CRUD**: 创建、查询、更新、删除充电站
- **列表查询**: 分页、搜索、状态筛选
- **实时数据**: 动态计算正在充电数和故障数
- **数据验证**: 名称唯一性、关联数据检查

### 3. 营收统计模块

- **图表数据**: 最近7个月销售和访问量统计
- **营收列表**: 各充电站营收详情（分页、搜索）
- **收入分类**: 电费、停车费、服务费、会员储值金
- **增长分析**: 日增长率和月增长率统计

### 4. 充电桩监控模块

- **实时监控**: 所有充电桩的实时状态监控
- **状态管理**: 6种充电桩状态（空闲、充电中、连接中等）
- **设备参数**: 电压、电流、功率、温度等实时数据
- **使用记录**: 每个充电桩的最近使用记录

### 5. 权限控制系统

- **三级权限**: 管理员、运营专员、普通用户
- **菜单权限**: 基于角色的动态菜单显示
- **按钮权限**: 细粒度的操作权限控制
- **安全机制**: 防止权限越权访问

## 数据库设计

### 核心数据表

1. **user** - 后台管理用户表
2. **charging_user** - 充电用户表
3. **station** - 充电站表
4. **pile** - 充电桩表
5. **order** - 充电订单表
6. **revenue** - 营收统计表
7. **alarm** - 报警记录表
8. **role** - 角色表

### 关键关联关系

- Station → Pile (一对多)
- Station → Order (一对多)
- Station → Revenue (一对多)
- ChargingUser → Order (一对多)
- User → Role (多对一)

## API接口设计

### RESTful风格

采用标准的RESTful API设计：

- **GET** `/api/stations` - 获取充电站列表
- **GET** `/api/stations/:id` - 获取单个充电站
- **POST** `/api/stations` - 创建充电站
- **PUT** `/api/stations/:id` - 更新充电站
- **DELETE** `/api/stations/:id` - 删除充电站

### 统一响应格式

```typescript
{
  code: number;        // 状态码
  message: string;     // 提示信息
  data: any;          // 响应数据
}
```

### 认证机制

- 使用JWT进行身份认证
- 请求头携带：`Authorization: Bearer <token>`
- 中间件自动验证和解析用户信息

## 开发环境配置

### 环境要求

- Node.js >= 18
- MySQL >= 5.7
- npm 或 yarn

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd chargingStation
   ```

2. **安装后端依赖**
   ```bash
   cd server
   npm install
   ```

3. **配置环境变量**
   ```bash
   # 创建 .env 文件
   cp .env.example .env
   # 编辑数据库配置
   ```

4. **创建数据库**
   ```sql
   CREATE DATABASE charging_station CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

5. **启动后端服务**
   ```bash
   npm run dev
   ```

6. **安装前端依赖**
   ```bash
   cd ../admin
   npm install
   ```

7. **启动前端服务**
   ```bash
   npm run dev
   ```

### 环境变量配置

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_DATABASE=charging_station

# JWT配置
JWT_SECRET=your_jwt_secret

# 服务端口
PORT=3001
```

```dockerfile

WORKDIR /app
COPY package*.json ./

COPY . .

EXPOSE 3001
CMD ["npm", "start"]
```

## 常见问题

### 1. 启动问题

**Q: 启动时报错 "ECMAScript imports and exports cannot be written in a CommonJS file"**

A: 确保 `package.json` 中设置了 `"type": "module"`

**Q: 数据库连接失败**

A: 检查 `.env` 文件中的数据库配置，确保MySQL服务已启动

### 2. 开发问题

**Q: TypeScript编译错误**

A: 检查 `tsconfig.json` 配置，确保使用了正确的模块解析方式

**Q: 接口认证失败**

A: 确保请求头中携带了有效的JWT令牌

### 3. 部署问题

**Q: 生产环境启动失败**

A: 检查环境变量配置，确保数据库连接正常
