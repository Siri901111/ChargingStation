# 启动问题排查指南

## 问题：应用崩溃，无法启动

### 第一步：检查 .env 文件

在 `server` 目录下创建 `.env` 文件（如果不存在）：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_DATABASE=charging_station
JWT_SECRET=super_secret_jwt_key
PORT=3001
```

**重要：** 将 `DB_PASSWORD` 改为你的实际 MySQL 密码！

### 第二步：检查 MySQL 服务

1. 确保 MySQL 服务已启动
2. 打开 MySQL 命令行或 MySQL Workbench
3. 创建数据库：
```sql
CREATE DATABASE charging_station CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 第三步：检查依赖

确保已安装所有依赖：
```bash
cd server
npm install
```

### 第四步：启动项目

```bash
npm run dev
```

### 常见错误及解决方案

#### 1. `ECONNREFUSED` - 连接被拒绝
- **原因：** MySQL 服务未启动
- **解决：** 启动 MySQL 服务

#### 2. `Access denied` - 访问被拒绝
- **原因：** 数据库用户名或密码错误
- **解决：** 检查 `.env` 文件中的 `DB_USER` 和 `DB_PASSWORD`

#### 3. `Unknown database` - 数据库不存在
- **原因：** 数据库 `charging_station` 未创建
- **解决：** 执行创建数据库的 SQL 语句

#### 4. `Cannot find module` - 找不到模块
- **原因：** 依赖未安装
- **解决：** 运行 `npm install`

### 验证启动成功

看到以下信息表示启动成功：
```

✅ 数据库表结构同步成功！
✅ 默认管理员账号创建成功！
🚀 Server running at http://localhost:3001
```
