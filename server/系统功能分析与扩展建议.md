#### 2. 充电桩使用记录管理

**功能描述**: 记录每个充电桩的使用历史

**需要的数据表**:
```sql
CREATE TABLE `pile_usage_record` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `pile_id` BIGINT NOT NULL COMMENT '充电桩ID',
  `order_id` VARCHAR(64) COMMENT '订单号',
  `user_id` BIGINT COMMENT '用户ID',
  `start_time` DATETIME COMMENT '开始时间',
  `end_time` DATETIME COMMENT '结束时间',
  `electricity_amount` DECIMAL(10,2) COMMENT '充电量（度）',
  `voltage` VARCHAR(20) COMMENT '电压',
  `current` VARCHAR(20) COMMENT '电流',
  `power` VARCHAR(20) COMMENT '功率',
  `temperature` VARCHAR(20) COMMENT '温度',
  `status` TINYINT COMMENT '状态：1空闲，2充电中，3连接中，4排队中，5已预约，6故障/离线',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`pile_id`) REFERENCES `pile`(`id`),
  FOREIGN KEY (`order_id`) REFERENCES `order`(`order_no`),
  FOREIGN KEY (`user_id`) REFERENCES `charging_user`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='充电桩使用记录表';
```

**需要的接口**:
- `GET /api/piles/:id/usage-records` - 获取充电桩使用记录（分页）
- `GET /api/piles/:id/usage-stats` - 获取充电桩使用统计

#### 3. 充电桩维保管理

**功能描述**: 管理充电桩的维保记录和计划

```sql
CREATE TABLE `pile_maintenance` (

  `maintenance_time` DATETIME COMMENT '维保时间',

  `maintenance_cost` DECIMAL(10,2) COMMENT '维保费用',
  `next_maintenance_time` DATETIME COMMENT '下次维保时间',
  `status` TINYINT COMMENT '状态：1已完成，2进行中，3已计划',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`pile_id`) REFERENCES `pile`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='充电桩维保记录表';
```

**需要的接口**:
