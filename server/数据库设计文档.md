# 充电站管理系统 - 数据库设计文档

## 系统概述

这是一个**充电站后台管理系统**的数据库设计，支持充电站管理、用户权限管理、营收统计、设备监控等功能。

## 业务场景说明

### 用户类型

系统涉及两类不同的用户：

#### 1. 后台管理用户（User表）
- **用途**：后台管理系统的工作人员
- **角色**：管理员(admin)、运营专员(manager)、普通员工(user)
- **功能**：登录后台系统、管理充电站、查看数据、处理订单等

#### 2. 充电用户（ChargingUser表）
- **用途**：使用充电桩充电的终端用户（车主）
- **功能**：充电消费、产生订单、会员卡管理等
- **注意**：这些用户不登录后台管理系统

## 数据库表结构

### 1. 后台管理用户表 (user)

存储后台管理系统的用户信息。

```sql
CREATE TABLE `user` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `account` VARCHAR(64) NOT NULL UNIQUE COMMENT '账号',
  `password` VARCHAR(256) NOT NULL COMMENT '密码（加密）',
  `name` VARCHAR(32) NOT NULL COMMENT '姓名',
  `phone` VARCHAR(16) COMMENT '手机号',
  `id_no` VARCHAR(24) COMMENT '身份证号',
  `position` VARCHAR(32) COMMENT '职位',
  `department` VARCHAR(32) COMMENT '部门',
  `status` TINYINT DEFAULT 1 COMMENT '状态：1启用，0禁用',
  `page_authority` VARCHAR(512) COMMENT '页面权限：admin/manager/user',
  `btn_authority` VARCHAR(512) COMMENT '按钮权限：add,edit,delete等',
  `role_id` BIGINT COMMENT '角色ID',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='后台管理用户表';
```

**字段说明**：
- `account`: 登录账号，唯一
- `password`: bcrypt加密的密码
- `page_authority`: 页面权限级别（admin/manager/user）
- `btn_authority`: 按钮权限，逗号分隔
- `status`: 账号状态，0禁用1启用

### 2. 充电用户表 (charging_user)

存储使用充电桩的终端用户信息。

```sql
CREATE TABLE `charging_user` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `phone` VARCHAR(16) NOT NULL UNIQUE COMMENT '手机号',
  `name` VARCHAR(32) COMMENT '姓名',
  `id_no` VARCHAR(24) COMMENT '身份证号',
  `member_card_no` VARCHAR(32) COMMENT '会员卡号',
  `balance` DECIMAL(10,2) DEFAULT 0.00 COMMENT '余额',
  `status` TINYINT DEFAULT 1 COMMENT '状态：1正常，0禁用',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='充电用户表';
```

**字段说明**：
- `phone`: 手机号作为唯一标识
- `member_card_no`: 会员卡号
- `balance`: 账户余额

### 3. 角色表 (role)

定义用户角色。

```sql
CREATE TABLE `role` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(32) NOT NULL COMMENT '角色名称'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='角色表';
```

**默认数据**：
```sql
INSERT INTO `role` VALUES

(2, '运营专员'),

```

### 4. 充电站表 (station)

存储充电站基本信息。

```sql
CREATE TABLE `station` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(100) NOT NULL COMMENT '站点名称',
  `city` VARCHAR(30) COMMENT '所属城市',
  `fast` INT COMMENT '快充数量',
  `slow` INT COMMENT '慢充数量',
  `status` TINYINT DEFAULT 1 COMMENT '状态：2使用中，3空闲中，4维护中，5待维修',
  `now` INT COMMENT '正在充电数（实时计算，不存储）',
  `fault` INT COMMENT '故障数（实时计算，不存储）',
  `person` VARCHAR(50) COMMENT '站点负责人',
  `tel` VARCHAR(16) COMMENT '负责人电话',
  `longitude` FLOAT COMMENT '经度',
  `latitude` FLOAT COMMENT '纬度'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='充电站表';
```

**字段说明**：
- `name`: 站点名称，必须唯一
- `fast/slow`: 快充/慢充桩数量
- `now/fault`: 实时计算字段，不实际存储
- `longitude/latitude`: GPS坐标

---

### 5. 充电桩表 (pile)

存储充电桩设备信息。

```sql
CREATE TABLE `pile` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `station_id` BIGINT NOT NULL COMMENT '所属充电站ID',
  `type` VARCHAR(16) COMMENT '充电桩类型：快充/慢充',
  `status` TINYINT COMMENT '状态：1空闲，2充电中，3连接中，4排队中，5已预约，6故障/离线',
  `percent` INT COMMENT '充电百分比（0-100）',
  `voltage` FLOAT COMMENT '电压值',
  `current` FLOAT COMMENT '电流值',
  `power` FLOAT COMMENT '功率值',
  `temperature` FLOAT COMMENT '温度值',
  `install_date` DATE COMMENT '安装日期',
  FOREIGN KEY (`station_id`) REFERENCES `station`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='充电桩表';
```

**字段说明**：
- `station_id`: 关联充电站
- `status`: 充电桩实时状态
- `percent`: 充电进度百分比
- 物理参数：电压、电流、功率、温度

---

### 6. 充电订单表 (order)

存储充电订单信息。

```sql
CREATE TABLE `order` (
  `order_no` VARCHAR(64) PRIMARY KEY COMMENT '订单号',
  `user_id` BIGINT NOT NULL COMMENT '充电用户ID',
  `equipment_no` VARCHAR(64) COMMENT '设备编号（充电桩ID）',
  `station_id` BIGINT COMMENT '充电站ID',
  `date` DATETIME COMMENT '订单日期',
  `start_time` DATETIME COMMENT '开始充电时间',
  `end_time` DATETIME COMMENT '结束充电时间',
  `money` DECIMAL(10,2) COMMENT '消费金额',
  `pay` VARCHAR(20) COMMENT '支付方式',
  `status` TINYINT COMMENT '订单状态：2进行中，3已完成，4异常',
  FOREIGN KEY (`user_id`) REFERENCES `charging_user`(`id`),
  FOREIGN KEY (`station_id`) REFERENCES `station`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='充电订单表';
```

**字段说明**：
- `order_no`: 订单号作为主键
- `user_id`: 关联充电用户（非后台用户）
- `equipment_no`: 充电桩设备编号
- `money`: 订单金额

---

### 7. 营收统计表 (revenue)

存储各充电站的营收数据。

```sql
CREATE TABLE `revenue` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `station_id` BIGINT NOT NULL COMMENT '充电站ID',
  `day_date` DATE COMMENT '营收日期',
  `day` DECIMAL(10,2) COMMENT '单日收入',
  `month` DECIMAL(10,2) COMMENT '月度收入',
  `electricity` DECIMAL(10,2) COMMENT '电费营收',
  `parking_fee` DECIMAL(10,2) COMMENT '停车费营收',
  `service_fee` DECIMAL(10,2) COMMENT '服务费营收',
  `member` DECIMAL(10,2) COMMENT '会员储值金',
  `percent` DECIMAL(5,2) COMMENT '日增长百分比',
  `mpercent` DECIMAL(5,2) COMMENT '月增长百分比',
  FOREIGN KEY (`station_id`) REFERENCES `station`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='营收统计表';
```

**字段说明**：
- `day_date`: 营收统计日期
- 收入分类：电费、停车费、服务费、会员储值
- `percent/mpercent`: 增长率统计

### 8. 报警记录表 (alarm)

存储设备报警信息。

```sql
CREATE TABLE `alarm` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `station_id` BIGINT COMMENT '充电站ID',
  `pile_id` BIGINT COMMENT '充电桩ID',
  `title` VARCHAR(120) COMMENT '报警标题',
  `detail` VARCHAR(255) COMMENT '报警详情',
  `fault_time` DATETIME COMMENT '故障时间',
  `level` TINYINT COMMENT '报警级别：1严重，2紧急，3重要，4一般',
  `status` TINYINT DEFAULT 1 COMMENT '处理状态：1待指派，2处理中，3已处理，4处理异常',
  `handler` VARCHAR(50) COMMENT '处理人员',
  `handle_time` DATETIME COMMENT '处理时间',
  `handle_note` TEXT COMMENT '处理备注',
  `urge_count` INT DEFAULT 0 COMMENT '催办次数',
  `last_urge_time` DATETIME COMMENT '最后催办时间',
  FOREIGN KEY (`station_id`) REFERENCES `station`(`id`),
  FOREIGN KEY (`pile_id`) REFERENCES `pile`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='报警记录表';
```

**字段说明**：
- 可关联充电站或具体充电桩
- `level`: 报警级别分类（1严重，2紧急，3重要，4一般）
- `status`: 处理状态（1待指派，2处理中，3已处理，4处理异常）
- `fault_time`: 故障发生时间
- `handler`: 处理人员姓名
- `handle_time`: 开始处理时间
- `handle_note`: 处理过程备注
- `urge_count`: 催办次数统计
- `last_urge_time`: 最后一次催办时间

## 表关系图

```
User (后台管理用户)
├── belongsTo Role (多对一)
└── 无直接关联到Order（后台用户不产生充电订单）

ChargingUser (充电用户)
└── hasMany Order (一对多)

Station (充电站)
├── hasMany Pile (一对多)
├── hasMany Order (一对多)
├── hasMany Revenue (一对多)
└── hasMany Alarm (一对多)

Pile (充电桩)
├── belongsTo Station (多对一)
└── hasMany Alarm (一对多)

Order (充电订单)
├── belongsTo ChargingUser (多对一) - user_id 指向充电用户
├── belongsTo Station (多对一) - station_id
└── 关联 Pile 通过 equipment_no 字段

Revenue (营收记录)
└── belongsTo Station (多对一)

Alarm (报警记录)
├── belongsTo Station (多对一)
└── belongsTo Pile (多对一)

Role (角色)
└── hasMany User (一对多)
```

## 关键关联关系

### 1. Station ↔ Pile（充电站 ↔ 充电桩）
```sql
-- 一个充电站有多个充电桩
ALTER TABLE `pile` ADD FOREIGN KEY (`station_id`) REFERENCES `station`(`id`);
```

### 2. ChargingUser ↔ Order（充电用户 ↔ 订单）
```sql
-- 一个充电用户有多个订单
ALTER TABLE `order` ADD FOREIGN KEY (`user_id`) REFERENCES `charging_user`(`id`);
```

### 3. Station ↔ Order（充电站 ↔ 订单）
```sql
-- 一个充电站有多个订单
ALTER TABLE `order` ADD FOREIGN KEY (`station_id`) REFERENCES `station`(`id`);
```

### 4. Station ↔ Revenue（充电站 ↔ 营收）
```sql
-- 一个充电站有多条营收记录
ALTER TABLE `revenue` ADD FOREIGN KEY (`station_id`) REFERENCES `station`(`id`);
```

### 5. User ↔ Role（后台用户 ↔ 角色）
```sql
-- 多个用户属于一个角色
ALTER TABLE `user` ADD FOREIGN KEY (`role_id`) REFERENCES `role`(`id`);
```

## 业务流程说明

### 1. 用户管理流程

1. **后台管理员**（User表）登录系统
2. 管理员可以注册新的后台用户
3. 设置用户权限（页面权限和按钮权限）
4. 管理用户状态（启用/禁用）

### 2. 充电业务流程

1. **充电用户**（ChargingUser表）到充电站充电
2. 选择充电桩，连接车辆
3. 充电过程产生**订单**（Order表）
4. 系统记录充电数据和费用
5. 自动生成**营收记录**（Revenue表）

### 3. 设备监控流程

1. 充电桩实时上报状态数据
2. 系统更新充电桩状态（Pile表）
3. 设备异常时生成**报警记录**（Alarm表）
4. **后台管理员**通过系统查看和处理

## 重要说明

### ❌ 常见误解

- **User表 与 Order表 没有直接关联**
- Order表中的 `user_id` 不是指向 User表（后台管理用户）
- 而是指向 ChargingUser表（充电用户）

### ✅ 正确理解

- **User表**：后台管理系统的工作人员，用于系统管理
- **ChargingUser表**：充电站的终端用户，产生充电订单
- **Order表**：充电订单，由充电用户产生，在充电站的充电桩上完成

### 数据一致性

1. **实时计算字段**：`station.now` 和 `station.fault` 通过查询 `pile` 表实时计算
2. **营收数据**：建议每日定时任务生成营收统计数据
3. **状态同步**：充电桩状态需要与实际设备保持同步
4. **外键约束**：确保数据完整性，防止孤立数据

这样的设计符合实际业务场景，将管理端和业务端用户分离，便于权限管理和数据维护。
