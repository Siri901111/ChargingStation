# 快速启动指南

## 第一步：安装 tsx（新的 TypeScript 运行器）

```bash
cd server
npm install -D tsx
```

## 第二步：确保 .env 文件存在

在 `server` 目录下创建 `.env` 文件：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_DATABASE=charging_station
JWT_SECRET=super_secret_jwt_key
PORT=3001
```

**重要：** 将 `DB_PASSWORD` 改为你的实际 MySQL 密码！

## 第三步：创建数据库

打开 MySQL 命令行或 MySQL Workbench，执行：

```sql
CREATE DATABASE charging_station CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 第四步：启动项目

```bash
npm run dev
```

## 预期输出

启动成功后应该看到：

```

✅ 数据库表结构同步成功！
✅ 默认管理员账号创建成功！
   账号: admin
   密码: admin123
🚀 Server running at http://localhost:3001
📝 API 文档: http://localhost:3001/api
```

## 验证数据库表

启动成功后，在 MySQL 中执行：

```sql
USE charging_station;
SHOW TABLES;
```

应该能看到以下表：
- user
- station
- pile
- order
- revenue
- alarm
- notice
- role
- permission

## 如果还有问题

1. **检查 MySQL 服务是否启动**
2. **检查 .env 文件中的数据库密码是否正确**
3. **检查数据库是否已创建**
4. **查看控制台的错误信息，按照提示操作**
