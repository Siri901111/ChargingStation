# 移动端功能更新说明

## 更新日期
2024年更新

## 新增功能

### 1. 站点收藏功能 ✅

#### 功能描述
用户可以将喜欢的充电站添加到收藏列表，方便快速访问。

#### 功能特性
- 收藏/取消收藏站点
- 查看收藏列表
- 站点详情页显示收藏状态
- 收藏列表支持跳转站点详情

#### 数据库变更
新增 `user_favorite` 表，用于存储用户收藏的站点信息。

```sql
CREATE TABLE `user_favorite` (
  `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `user_id` BIGINT NOT NULL COMMENT '用户ID（充电用户）',
  `station_id` BIGINT NOT NULL COMMENT '站点ID',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '收藏时间',
  UNIQUE KEY `uk_user_station` (`user_id`, `station_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_station_id` (`station_id`),
  FOREIGN KEY (`user_id`) REFERENCES `charging_user`(`id`),
  FOREIGN KEY (`station_id`) REFERENCES `station`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户收藏表';
```

#### API接口
- `POST /api/mobile/station/favorite` - 收藏站点
- `DELETE /api/mobile/station/favorite/:id` - 取消收藏
- `GET /api/mobile/station/favorites` - 获取收藏列表
- `GET /api/mobile/station/:id` - 站点详情接口新增 `isFavorite` 字段

#### 页面路径
- `/pages/favorite/index` - 收藏列表页面

### 2. 充电统计功能 ✅

#### 功能描述
展示用户的充电数据统计，包括累计充电次数、总电量、总费用等。

#### 功能特性
- 累计统计：累计充电次数、总电量(kWh)、总费用
- 本月统计：本月充电次数、本月消费金额
- 数据明细列表展示

#### API接口
使用现有的 `GET /api/mobile/order/statistics` 接口。

#### 页面路径
- `/pages/statistics/index` - 充电统计页面
