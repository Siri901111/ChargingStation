# 扫码充电功能完整规划方案

## 📋 功能概述

扫码充电是充电桩管理系统的核心功能之一，用户通过扫描充电桩上的二维码来启动充电，系统实时监控充电状态，充电完成后自动结算。

## 🎯 功能模块划分

### 1. 管理端功能（管理员使用）

#### 1.1 充电桩二维码管理
- **生成二维码**：为每个充电桩生成唯一的二维码
- **二维码格式**：支持多种格式（PILE_123、纯数字、JSON格式）
- **二维码预览**：在管理页面可以预览二维码
- **下载二维码**：支持下载PNG格式的二维码图片，用于打印粘贴

#### 1.2 充电桩状态监控
- **实时状态**：查看充电桩当前状态（空闲/充电中/故障/离线）
- **使用记录**：查看充电桩的历史使用记录
- **维保记录**：查看充电桩的维保历史

### 2. 用户端功能（普通用户使用）

#### 2.1 扫码功能
- **二维码扫描**：
  - 小程序：使用 camera 组件实时扫描
  - H5：支持手动输入充电桩编号（开发环境友好）
  - APP：使用原生扫码功能
- **扫码识别**：
  - 支持多种二维码格式
  - 智能识别充电桩编号
  - 错误提示和引导

#### 2.2 充电桩信息展示
- **基本信息**：
  - 充电桩名称和编号
  - 所属充电站
  - 充电类型（快充/慢充）
  - 额定功率
  - 当前电价
- **状态展示**：
  - 实时状态（空闲/充电中/故障/离线）
  - 状态颜色标识
- **注意事项**：充电须知和安全提示

#### 2.3 开始充电流程
- **前置检查**：
  - 用户是否登录
  - 账户余额是否充足（≥10元）
  - 充电桩是否可用
  - 是否已有进行中的订单
- **确认提示**：显示充电桩信息和电价，用户确认
- **创建订单**：生成订单号，更新充电桩状态
- **跳转充电页面**：自动跳转到充电中页面

#### 2.4 充电中监控
- **实时数据展示**：
  - 充电时长（时分秒格式）
  - 已充电量（kWh）
  - 当前费用（元）
  - 实时功率（kW）
  - 电压（V）
  - 电流（A）
  - 电池电量百分比（模拟）
- **可视化展示**：
  - 圆形进度条显示电量百分比
  - 充电动画效果
  - 数据图表（可选）
- **实时更新**：
  - WebSocket 实时推送数据
  - 轮询备份机制（如果WebSocket失败）
- **停止充电**：
  - 确认提示
  - 停止充电并结算
  - 跳转到订单详情

#### 2.5 充电记录
- **记录列表**：
  - 按时间倒序展示
  - 支持分页加载
  - 下拉刷新
- **记录信息**：
  - 充电站名称
  - 充电桩名称
  - 充电时长
  - 充电量（kWh）
  - 费用（元）
  - 充电时间
  - 订单状态
- **详情查看**：
  - 点击记录查看详细信息
  - 支持查看订单详情

## 🔄 业务流程

### 用户扫码充电流程

```
1. 用户打开扫码页面
   ↓
2. 扫描/输入充电桩二维码
   ↓
3. 系统识别并查询充电桩信息
   ↓
4. 展示充电桩信息（状态、类型、电价等）
   ↓
5. 用户确认开始充电
   ↓
6. 系统检查：
   - 用户是否登录 ✓
   - 余额是否充足（≥10元）✓
   - 充电桩是否空闲 ✓
   - 是否已有进行中的订单 ✓
   ↓
7. 创建订单，更新充电桩状态为"充电中"
   ↓
8. 跳转到充电中页面
   ↓
9. 实时监控充电状态（WebSocket/轮询）
   ↓
10. 用户点击"停止充电"
    ↓
11. 系统计算费用：
    - 充电时长
    - 充电量（根据功率和时长计算）
    - 电费（充电量 × 单价）
    - 服务费（电费 × 10%）
    - 总费用
    ↓
12. 从用户余额扣款
    ↓
13. 更新订单状态为"已完成"
    ↓
14. 更新充电桩状态为"空闲"
    ↓
15. 显示充电完成信息
    ↓
16. 跳转到订单详情页面
```

## 🔧 技术实现要点

### 1. 二维码生成
- **后端生成**：使用 `qrcode` 库生成二维码
- **格式规范**：
  - 简单格式：`PILE_123`（推荐）
  - 数字格式：`123`
  - JSON格式：`{"pileId": 123}`（扩展用）
- **存储方式**：
  - 管理端实时生成，不存储
  - 支持下载PNG格式

### 2. 扫码识别
- **格式解析**：
  - 优先识别 `PILE_` 前缀
  - 其次识别纯数字
  - 最后尝试JSON解析
- **错误处理**：
  - 无效格式提示
  - 充电桩不存在提示
  - 网络错误提示

### 3. 实时监控
- **WebSocket**：
  - 连接地址：`ws://host/charging/{orderId}`
  - 消息格式：`{type: 'charging_status', payload: {...}}`
  - 心跳保活
- **轮询备份**：
  - 如果WebSocket失败，使用HTTP轮询
  - 每3秒请求一次状态
- **数据模拟**：
  - 基于时长计算模拟数据
  - 添加随机波动模拟真实情况

### 4. 费用计算
- **计算规则**：
  - 充电量 = 平均功率 × 充电时长（小时）
  - 电费 = 充电量 × 电价
  - 服务费 = 电费 × 10%
  - 总费用 = 电费 + 服务费
- **精度处理**：
  - 金额保留2位小数
  - 充电量保留2位小数

### 5. 状态管理
- **Pinia Store**：
  - `isCharging`：是否正在充电
  - `chargingStatus`：充电状态数据
  - `wsConnection`：WebSocket连接
- **数据持久化**：
  - 订单数据存储在数据库
  - 本地缓存充电状态（刷新后恢复）

## 🐛 异常处理

### 1. 扫码异常
- 无效二维码 → 提示"无效的充电桩二维码"
- 充电桩不存在 → 提示"充电桩不存在"
- 网络错误 → 提示"网络错误，请重试"

### 2. 开始充电异常
- 未登录 → 跳转到登录页面
- 余额不足 → 提示"余额不足，请先充值"，跳转充值页面
- 充电桩不可用 → 提示"充电桩当前不可用"
- 已有进行中的订单 → 提示"您已有进行中的充电订单"，跳转到充电中页面

### 3. 充电中异常
- WebSocket断开 → 自动切换到轮询模式
- 网络中断 → 提示"网络连接已断开，正在重连..."
- 充电桩故障 → 提示"充电桩异常，请立即停止充电"

### 4. 停止充电异常
- 扣款失败 → 订单标记为"待支付"，提示用户联系客服
- 网络错误 → 提示"停止失败，请重试"
