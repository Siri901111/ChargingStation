- ✅ 创建了 `.env.example` 示例文件

## 🔧 常见问题

### 1. 接口请求失败（CORS错误）

**问题：** 浏览器控制台显示 CORS 跨域错误

**解决：**
- 检查后端CORS配置
- 确认前端请求的域名和端口
- 后端需要允许前端域名访问

### 2. 401 未授权错误

**问题：** 接口返回401错误

**解决：**
- 检查登录是否成功，token是否正确保存
- 检查token是否过期
- 确认后端认证中间件正常工作

### 3. 环境变量不生效

**问题：** 修改环境变量后不生效

**解决：**
- 确认环境变量以 `VITE_` 开头
- 重启开发服务器（`npm run dev`）
- 检查 `.env` 文件是否在 `admin` 目录下

### 4. 接口路径不匹配

**问题：** 404错误，接口路径不存在

**解决：**
- 检查前端API调用路径
- 检查后端路由配置
- 确认接口路径是否一致（注意大小写）
