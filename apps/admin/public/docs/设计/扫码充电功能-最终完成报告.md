## ⚠️ 已知问题

### 1. TypeScript类型检查警告

**问题**: `apps/admin/src/views/chargingstation/Fault.vue` 中导入 `PileQRCode` 组件时，TypeScript报错："Module has no default export"

**原因**: Vue 3的 `<script setup>` 语法会自动导出组件，但TypeScript类型检查可能无法正确识别

**解决方案**: 
- 这是TypeScript类型检查问题，运行时不会有问题
- 如果需要修复，可以在组件导出时显式添加类型定义

**状态**: 不影响功能，可以忽略
