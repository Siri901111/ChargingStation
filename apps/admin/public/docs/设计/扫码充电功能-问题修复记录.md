### 3. ✅ WebSocket 连接失败问题

**问题描述**：
- WebSocket连接失败：`WebSocket connection to 'ws://localhost:3001/charging/...' failed`
- 后端服务器未实现WebSocket支持
- 连接失败后无法获取实时充电状态

**修复方案**：
- 添加了WebSocket连接失败检测
- 实现了轮询（Polling）作为备选方案
- WebSocket连接失败时自动切换到轮询模式
- 每5秒轮询一次充电状态

**修改文件**：
- `apps/user-app/src/store/modules/charging.ts`

**修改内容**：

1. **WebSocket连接优化**：
   - 添加了连接失败检测
   - 添加了错误处理回调
   - 连接失败时自动启动轮询

2. **轮询功能实现**：
   - `startPolling(orderId)` - 开始轮询充电状态
   - `stopPolling()` - 停止轮询
   - 每5秒调用一次 `fetchChargingStatus()`

3. **错误处理**：
   - WebSocket连接错误时自动切换到轮询
   - WebSocket连接关闭时自动切换到轮询
   - 充电停止时自动停止轮询

**代码逻辑**：
```typescript
// WebSocket连接失败时的处理流程
1. 尝试连接WebSocket
2. 如果连接失败 -> 自动启动轮询
3. 如果连接成功但后续关闭 -> 自动启动轮询
4. 如果连接成功 -> 使用WebSocket接收实时数据
5. 充电停止时 -> 停止WebSocket和轮询
```
