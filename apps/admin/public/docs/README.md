# 充电站管理系统 - 文档中心

## 项目概述

本项目是一个充电站管理系统，采用 Monorepo 架构，包含管理后台、移动端用户应用、后端服务和监控 SDK。

### 技术栈

| 模块 | 技术栈 |
|------|--------|
| 管理后台 (admin) | Vue 3 + TypeScript + Vite + Element Plus + TailwindCSS |
| 移动端 (user-app) | uni-app + Vue 3 + TypeScript + Pinia |
| 后端 (server) | Node.js + Express 5 + TypeScript + Sequelize + MySQL |
| 监控 SDK | TypeScript + tsup |
| 架构 | pnpm + Turborepo Monorepo |

## 项目结构

```
chargingStation/
├── apps/                       # 应用目录
│   ├── admin/                  # Vue 3 管理后台
│   ├── user-app/               # uni-app 移动端应用
│   └── server/                 # Express 后端服务
├── packages/                   # 共享包目录
│   ├── monitor-sdk/            # 前端监控 SDK
│   ├── shared-types/           # 共享类型定义
│   ├── shared-utils/           # 共享工具函数
│   ├── tsconfig/               # 统一 TS 配置
│   └── eslint-config/          # 统一 ESLint 配置
└── docs/                       # 文档中心
    ├── api/                    # API 接口文档
    ├── guides/                 # 使用指南
    ├── mobile/                 # 移动端文档
    └── design/                 # 设计文档
```

## 常用命令

```bash
# 安装依赖
pnpm install

# 启动所有项目
pnpm dev

# 只启动管理后台
pnpm dev:admin

# 只启动后端
pnpm dev:server

# 启动移动端 H5
pnpm dev:user-app

# 构建所有项目
pnpm build
```

## 核心功能模块

### 管理后台

| 功能 | 说明 |
|------|------|
| 数据看板 | 实时数据统计、趋势图表、状态分布 |
| 充电站管理 | 站点 CRUD、实时监控、故障管理 |
| 充电桩管理 | 设备管理、状态监控、维护记录 |
| 订单管理 | 订单查询、统计分析、导出功能 |
| 营收统计 | 收入分析、月度报表、多维度统计 |
| 报警管理 | 告警列表、处理记录、统计分析 |
| 电子地图 | 站点分布、区域统计、高德地图集成 |
| 用户管理 | 用户 CRUD、权限管理、角色分配 |

### 移动端用户应用

| 功能 | 说明 |
|------|------|
| 用户认证 | 手机号验证码登录、微信登录 |
| 附近充电站 | 定位获取、距离计算、站点搜索 |
| 扫码充电 | 扫码识别充电桩、实时充电状态 |
| 订单管理 | 订单列表、订单详情、充电记录 |
| 钱包充值 | 余额查询、套餐充值、测试充值 |
