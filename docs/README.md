# 充电站管理系统 - 文档中心

## 项目概述

本项目是一个充电站管理系统，采用 Monorepo 架构，包含前端管理后台、后端服务和监控 SDK。

### 技术栈

| 模块 | 技术栈 |
|------|--------|
| 前端 (admin) | Vue 3 + TypeScript + Vite + Element Plus + TailwindCSS |
| 后端 (server) | Node.js + Express 5 + TypeScript + Sequelize + MySQL |
| 监控 SDK | TypeScript + tsup |
| 架构 | pnpm + Turborepo Monorepo |

## 项目结构

```
chargingStation/
├── apps/                       # 应用目录
│   ├── admin/                  # Vue 3 前端管理系统
│   └── server/                 # Express 后端服务
├── packages/                   # 共享包目录
│   ├── monitor-sdk/            # 前端监控 SDK
│   ├── shared-types/           # 共享类型定义
│   ├── shared-utils/           # 共享工具函数
│   ├── tsconfig/               # 统一 TS 配置
│   └── eslint-config/          # 统一 ESLint 配置
└── docs/                       # 文档中心
    ├── api/                    # API 接口文档
    ├── guides/                 # 使用指南
    └── design/                 # 设计文档
```

## 常用命令

```bash
# 安装依赖
pnpm install

# 启动所有项目
pnpm dev

# 只启动前端
pnpm dev:admin

# 只启动后端
pnpm dev:server

# 构建所有项目
pnpm build

# 只构建前端
pnpm build:admin

# 只构建后端
pnpm build:server
```

## 核心功能模块

### 业务功能

| 功能 | 说明 |
|------|------|
| 数据看板 | 实时数据统计、趋势图表、状态分布 |
| 充电站管理 | 站点 CRUD、实时监控、故障管理 |
| 充电桩管理 | 设备管理、状态监控、维护记录 |
| 订单管理 | 订单查询、统计分析、导出功能 |
| 营收统计 | 收入分析、月度报表、多维度统计 |
| 报警管理 | 告警列表、处理记录、统计分析 |
| 电子地图 | 站点分布、区域统计、高德地图集成 |
| 用户管理 | 用户 CRUD、权限管理、角色分配 |
| 个人中心 | 个人信息、密码修改、通知管理 |

### 前端监控

| 功能 | 说明 |
|------|------|
| 错误监控 | JS错误、Promise异常、Vue组件错误捕获 |
| 性能监控 | FCP、LCP、FID、CLS 等 Web Vitals 指标 |
| 行为监控 | 页面访问、点击事件、路由变化追踪 |
| 网络监控 | HTTP 请求监控、响应时间、错误状态 |
| 用户追踪 | 用户行为轨迹、错误回放、活跃用户统计 |
