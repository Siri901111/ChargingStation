# 充电站管理平台 - 项目文档总览

## 项目简介

这是一个**新能源汽车充电站管理平台**的全栈系统，包含**管理后台**和**移动端应用**。系统采用前后端分离架构，提供充电站管理、用户权限管理、营收统计、设备监控、移动端充电服务等完整功能。

### 系统组成

- **管理后台** (`apps/admin`): Vue 3 + TypeScript + Element Plus，供运营人员使用
- **移动端应用** (`apps/user-app`): uni-app + Vue 3 + TypeScript，支持小程序和H5，供终端用户使用
- **后端服务** (`apps/server`): Node.js + Express + TypeScript + MySQL，提供RESTful API服务

### 项目特点

- ✅ **全栈开发**: 前后端分离，职责清晰
- ✅ **多端支持**: 管理后台（Web）+ 移动端（小程序/H5）
- ✅ **类型安全**: TypeScript 全栈开发
- ✅ **现代化技术栈**: Vue 3、uni-app、Express、Sequelize
- ✅ **完整业务功能**: 充电站管理、订单管理、支付、监控等
- ✅ **权限系统**: 基于角色的权限控制（RBAC）
- ✅ **实时监控**: 充电桩实时状态监控
- ✅ **数据可视化**: 营收统计、数据看板

## 技术架构

### 后端技术栈

- **运行环境**: Node.js >= 18
- **Web框架**: Express.js
- **编程语言**: TypeScript
- **数据库**: MySQL >= 5.7
- **ORM框架**: Sequelize
- **身份认证**: JWT (JSON Web Tokens)
- **密码加密**: bcryptjs
- **开发工具**: nodemon + tsx
- **模块系统**: ESM (ES Modules)

### 管理后台技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **HTTP客户端**: Axios
- **图表库**: ECharts
- **地图**: 高德地图

### 移动端技术栈

- **框架**: uni-app + Vue 3 + TypeScript
- **构建工具**: Vite
- **状态管理**: Pinia
- **样式**: SCSS
- **地图**: 高德地图（H5）/ 腾讯地图（小程序）
- **支持平台**: 微信小程序、H5、APP（可扩展）

## 数据库设计

### 核心数据表

1. **user** - 后台管理用户表
2. **charging_user** - 充电用户表
3. **station** - 充电站表
4. **pile** - 充电桩表
5. **order** - 充电订单表
6. **revenue** - 营收统计表
7. **alarm** - 报警记录表
8. **role** - 角色表

### 关键关联关系

- Station → Pile (一对多)
- Station → Order (一对多)
- Station → Revenue (一对多)
- ChargingUser → Order (一对多)
- User → Role (多对一)

## API接口设计

### RESTful风格

采用标准的RESTful API设计：

- **GET** `/api/stations` - 获取充电站列表
- **GET** `/api/stations/:id` - 获取单个充电站
- **POST** `/api/stations` - 创建充电站
- **PUT** `/api/stations/:id` - 更新充电站
- **DELETE** `/api/stations/:id` - 删除充电站

### 统一响应格式

```typescript
{
  code: number;        // 状态码
  message: string;     // 提示信息
  data: any;          // 响应数据
}
```

### 认证机制

- 使用JWT进行身份认证
- 请求头携带：`Authorization: Bearer <token>`
- 中间件自动验证和解析用户信息

## 开发环境配置

### 环境要求

- Node.js >= 18
- MySQL >= 5.7
- npm 或 yarn

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd chargingStation
   ```

2. **安装后端依赖**
   ```bash
   cd server
   npm install
   ```

3. **配置环境变量**
   ```bash
   # 创建 .env 文件
   cp .env.example .env
   # 编辑数据库配置
   ```

4. **创建数据库**
   ```sql
   CREATE DATABASE charging_station CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

5. **启动后端服务**
   ```bash
   npm run dev
   ```

6. **安装前端依赖**
   ```bash
   cd ../admin
   npm install
   ```

7. **启动前端服务**
   ```bash
   npm run dev
   ```

### 环境变量配置

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_DATABASE=charging_station

# JWT配置
JWT_SECRET=your_jwt_secret

# 服务端口
PORT=3001
```

### 代码规范

1. **TypeScript严格模式** - 启用严格类型检查
2. **ESM模块** - 使用ES6模块语法
3. **统一命名** - 驼峰命名法，语义化命名
4. **错误处理** - 统一的错误处理机制
5. **日志记录** - 关键操作记录日志

### Git提交规范

```
feat: 新功能
fix: 修复bug

refactor: 代码重构
test: 测试相关
chore: 构建工具、依赖更新
```

1. **RESTful风格** - 遵循REST设计原则
2. **统一响应格式** - 所有接口使用统一的响应结构
3. **错误码规范** - 标准HTTP状态码 + 业务错误码
4. **参数验证** - 严格的输入参数验证
5. **权限控制** - 基于角色的访问控制

## 常见问题

### 1. 启动问题

**Q: 启动时报错 "ECMAScript imports and exports cannot be written in a CommonJS file"**

A: 确保 `package.json` 中设置了 `"type": "module"`

**Q: 数据库连接失败**

A: 检查 `.env` 文件中的数据库配置，确保MySQL服务已启动

### 2. 开发问题

**Q: TypeScript编译错误**

A: 检查 `tsconfig.json` 配置，确保使用了正确的模块解析方式

**Q: 接口认证失败**

A: 确保请求头中携带了有效的JWT令牌

### 3. 部署问题

**Q: 生产环境启动失败**

A: 检查环境变量配置，确保数据库连接正常
